# Đối chiếu rubric A2.2

| Tiêu chí | Trọng số | Sản phẩm / minh chứng |
| --- | --- | --- |
| TC1 | 20% | Repository công khai, trên 3 commit, feat/docs/fix có thay đổi thực tế. |
| TC2 | 15% | README có local và demo; AI_LOG khai báo phạm vi, kết quả, cách tự kiểm chứng. |
| TC3 | 30% | GitHub Pages và workflow thành công; verify.py --online so khớp HTML/CSS/JS. |
| TC4 | 20% | RELEASE_NOTES, tag/release v1.0.0 khi phát hành; VERIFICATION mô tả chuỗi kiểm chứng. |
| TC5 | 15% | docs/DEMO.md có kịch bản và phản biện; sinh viên phải tự demo. |

Đây là đối chiếu đầu việc, không phải cam kết điểm. Sinh viên vẫn cần bổ sung thông tin cá nhân, tự kiểm tra, chụp minh chứng và nộp đúng quy định. Phạm vi dùng AI phải phù hợp quy định giảng viên.
